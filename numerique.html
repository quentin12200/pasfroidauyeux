Outils numeriques accessibles

Le numerique est un formidable outil d'autonomie pour les personnes deficientes visuelles. Votre telephone et votre ordinateur peuvent devenir de veritables assistants au quotidien. Voici comment les utiliser.

Par ou commencer ?

Si vous debutez, commencez par activer les fonctions d'accessibilite de votre telephone. C'est gratuit, deja installe, et ca change tout. Vous pouvez demander a un proche de vous aider pour la premiere configuration.

iPhone / iPad (iOS)

Apple est reconnu pour l'accessibilite de ses produits. Chaque iPhone inclut des fonctions puissantes pour les personnes deficientes visuelles.

  • VoiceOver : lecteur d'ecran integre. Il lit a voix haute tout ce qui s'affiche sur l'ecran. Activation : Reglages > Accessibilite > VoiceOver. Vous pouvez aussi dire "Dis Siri, active VoiceOver".
  • Zoom : agrandit tout l'ecran ou une partie. Activation : Reglages > Accessibilite > Zoom. Double-tapez avec trois doigts pour zoomer.
  • Taille du texte : agrandissez le texte dans toutes les applications. Reglages > Accessibilite > Affichage et taille du texte.
  • Loupe : utilisez l'appareil photo comme loupe pour lire les petits textes. Application "Loupe" integree.
  • Siri : l'assistant vocal permet de passer des appels, envoyer des messages, lancer des applications, tout par la voix.
  • Dictee vocale : parlez au lieu de taper. Appuyez sur l'icone microphone du clavier.

Android (Samsung, Google, etc.)

Les telephones Android disposent egalement de fonctions d'accessibilite integrees.

  • TalkBack : lecteur d'ecran d'Android. Lit tout ce qui s'affiche a l'ecran. Activation : Parametres > Accessibilite > TalkBack.
  • Agrandissement : zoomez en tapant trois fois sur l'ecran. Parametres > Accessibilite > Agrandissement.
  • Taille de la police : augmentez la taille du texte. Parametres > Accessibilite > Taille de la police.
  • Google Assistant : "OK Google" pour controler votre telephone a la voix.
  • Correction des couleurs : adaptez les couleurs de l'ecran a votre type de deficience visuelle. Parametres > Accessibilite > Correction des couleurs.

Applications utiles

Voici une selection d'applications particulierement utiles pour les personnes deficientes visuelles. La plupart sont gratuites.

Be My Eyes

Connectez-vous en video avec un benevole voyant qui vous aide a lire une etiquette, verifier une couleur, identifier un objet... Gratuit et disponible 24h/24.

Seeing AI (iOS)

Application Microsoft qui decrit ce que voit la camera : texte, visages, objets, billets de banque, couleurs. Gratuit.

Envision AI

Lit le texte a voix haute (courrier, etiquettes, ecrans), decrit les scenes, reconnait les visages. Version gratuite disponible.

KNFB Reader

Lecture de documents imprimes : prenez une photo et l'application lit le texte a voix haute. Tres precis.

Evelity

GPS d'interieur pour les lieux publics (gares, centres commerciaux). Guidage vocal pas a pas adapte aux personnes deficientes visuelles.

Soundscape (iOS)

Application Microsoft qui utilise le son 3D pour decrire votre environnement et vous aider a vous orienter.

Ordinateur accessible

Lecteurs d'ecran pour PC

  • NVDA (NonVisual Desktop Access) : lecteur d'ecran gratuit et open source pour Windows. Tres complet et regulierement mis a jour.
  • JAWS (Job Access With Speech) : lecteur d'ecran professionnel pour Windows. Payant mais financement possible via la PCH ou l'AGEFIPH.
  • Narrateur Windows : lecteur d'ecran integre a Windows. Moins complet mais suffisant pour debuter. Activation : touche Windows + Ctrl + Entree.
  • VoiceOver Mac : lecteur d'ecran integre a macOS. Activation : Cmd + F5 ou dans Preferences Systeme > Accessibilite.

Agrandissement sur PC

  • Loupe Windows : outil d'agrandissement integre. Touche Windows + "+" pour zoomer, Windows + "-" pour dezoomer.
  • ZoomText : logiciel professionnel d'agrandissement avec synthese vocale. Payant, financement possible.
  • Zoom navigateur : dans votre navigateur web, Ctrl + "+" agrandit la page, Ctrl + "-" la reduit, Ctrl + 0 revient a la taille normale.

Lecture et audio

  • Livres audio : Audible, Bibliotheque Sonore de l'AVH, applications de podcasts. De nombreuses bibliotheques municipales proposent aussi des livres audio.
  • Livres en braille numerique : si vous lisez le braille, des afficheurs braille peuvent se connecter a votre telephone ou ordinateur.
  • Journaux et magazines : de nombreux quotidiens proposent des versions audio ou sont lisibles par lecteur d'ecran.
  • Bibliotheque DAISY : format audio structure specialement concu pour les personnes empechees de lire (naviguer par chapitre, signet, etc.).

Se former au numerique accessible

Plusieurs associations proposent des formations gratuites a l'utilisation des outils numeriques adaptes : AVH, FAF, UNADEV... N'hesitez pas a vous renseigner. Un instructeur en informatique adaptee peut aussi intervenir a domicile via un SAMSAH.
